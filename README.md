# 🥗 FoodLoop — Closing the Loop on Food Waste

**FoodLoop** is a full-stack application designed to minimize food waste and fight food insecurity by connecting surplus food providers (restaurants, event organizers, and households) with nearby volunteers and individuals in need.

---

## ✨ Key Features

* **Surplus Food Listings:** Donors can quickly post available food items with quantity, pickup location, and expiration windows.
* **Interactive Discovery Map:** Volunteers and recipients can browse real-time, location-based food listings nearby.
* **Seamless Pickup Flow:** End-to-end status tracking from posting → claiming → pickup confirmation.
* **Role-Based Experience:** Dedicated workflows for food donors, delivery volunteers, and community recipients.
* **Expiry Alerts & Smart Suggestions:** Prioritizes items nearing expiration so surplus food gets claimed before spoiling.

## 🚀 Getting Started

### Prerequisites
* `[e.g., Node.js v18+ or Flutter SDK]`
* `[e.g., API Key for Maps / Database URI]`

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com
   cd foodloop
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure environment variables**
   Create a `.env` file in the root directory and add your keys:
   ```env
   PORT=5000
   DATABASE_URL=your_database_url
   MAPS_API_KEY=your_api_key
   ```

4. **Run the application**
   ```bash
   npm start
   ```
